Notify

Effects  fx.notify

What it does

Shows the player a message. Either a popup that stays until they dismiss it, or a toast that slides in and fades on its own.

When you'd use it

Reach for it whenever something happens that the player should notice. A balance changing, a door opening, a contact going quiet — none of those announce themselves.

Put it after the node that caused the change, never before. A message about money that has not arrived yet reads like a bug.

Keep it short. It sits over the game, so a player mid-task reads it at a glance or not at all.

In the game, this looks like

A box appears over the game. A notification waits for the player to close it. A toast slides in, holds for a moment, and fades.

Fields

Message

The text on the popup. Type {{data.name}} to insert a value you saved earlier.
What to put here
One or two sentences is plenty. It sits over the game, not in a journal.
Example
Payment received: Meridian Capital.
Default
empty

If you leave it empty
The popup appears with nothing in it. The player sees an empty box and no idea why.

Wires

SocketDirectionWhat to connect
Ininput Whatever should run immediately before this node.
Outoutput Whatever should happen after this node runs.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Step by step: add this node to a quest

  1. Find Notify under Effects in the palette.
  2. Drag it onto the canvas, after the node that caused the change.
  3. Wire the previous node's Out socket into this node's In socket.
  4. Type the message.
  5. Pick Style and Tone to match how much the message matters.

Common mistakes

  • The message fires before the thing it describes. Wire it after. The player reads about a payment, opens their bank, and finds nothing there.
  • Every message is a notification. Popups that wait for a click pile up. Save those for the moments that matter and use toasts for the rest.

Messages you might see

  • Unreachable — nothing leads to this node, so the player never sees the message
