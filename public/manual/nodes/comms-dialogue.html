Dialogue

Communication  comms.dialogue

What it does

A conversation between the player and a character: a phone call, a Kisscord chat, an e-mail or a WeeChat session.

When you'd use it

Use it for anything a character says to the player. Pick the form the story wants: a call for urgency, mail for a paper trail.

For phone calls, choose when Out fires: when the call hangs up, or right after it starts.

The second output is there for conversations that can go badly. Wire it if the player can answer wrongly.

In the game, this looks like

The conversation appears in the game's own phone, chat or mail, in the form you chose.

Fields

The inspector for this node is a conversation editor rather than a list of fields. Pick the kind of conversation, then write its lines in the editor that opens beside it.

Wires

SocketDirectionWhat to connect
Ininput Whatever should run immediately before the conversation.
Outoutput Whatever happens after the conversation. For phone calls, the Out-fires setting controls the exact timing.
Wrongoutput The path that runs when the conversation goes down its wrong branch.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Step by step: add this node to a quest

  1. Find Dialogue under Communication in the palette.
  2. Drag it onto the canvas where the conversation belongs.
  3. Pick the kind: phone call, Kisscord, e-mail or WeeChat.
  4. For phone calls, set Out fires before wiring the next beat.
  5. Write the lines in the conversation editor.
  6. Wire what should happen afterwards, and the wrong branch if there is one.

Common mistakes

  • The wrong branch is left unwired. A player who answers badly reaches a dead end. Wire it, or take the choice away.

Messages you might see

  • Unreachable — nothing leads to this node, so the conversation never starts
