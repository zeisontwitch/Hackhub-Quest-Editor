Claim another quest

Effects  fx.claimQuest

What it does

Accepts another quest for the player, so one story can lead into the next.

When you'd use it

Use it at the end of a quest that continues elsewhere. The player does not have to find and accept the next chapter themselves.

The quest you name has to exist. It can live in this mod or in another one the player has installed.

In the game, this looks like

The next quest appears in the player's list as accepted, and that quest's own opening runs.

Fields

Quest

The identifier of the quest to start next. It must exist in this mod or another installed one.
What to put here
The identifier of the quest to start next, exactly as that quest names itself.
Example
meridian-act-two
Default
empty
If you leave it empty
There is no quest to claim, so the node does nothing.
Watch out
The identifier has to match. A name that exists nowhere claims nothing, and the player is left with a finished story and no next chapter.

Wires

SocketDirectionWhat to connect
Ininput Whatever should run immediately before this node.
Outoutput Whatever should happen after this node runs.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Common mistakes

  • The identifier is spelled differently from the quest's own. Nothing is claimed and nothing warns you.
  • The next quest is not in the mod the player installed. It cannot be claimed. Ship the two together, or point at a quest the player already has.

Messages you might see

  • Unreachable — nothing leads to this node, so the next quest is never claimed

Related nodes

  • Pay the player — Deposits money in the player's bank.
  • Charge the player — Takes money out of the player's account.
  • Notify — Puts a message on the player's screen.
  • Ask player — Asks the player a one-line question.
  • Set quest data — Stores a value for later.
  • Complete quest — Finishes the current quest.
  • Retire quest — Removes the current quest without completion.
  • Unclaim quest — Removes a claimed quest.
  • Run terminal command — Runs a command in the player's terminal.
  • Open handbook — Opens an in-game article.
