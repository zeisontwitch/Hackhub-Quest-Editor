Sticky note

Layout  flow.note

What it does

A note on the canvas for you. It never reaches the player.

When you'd use it

Use it to leave yourself a reason: why this branch exists, what a placeholder is standing in for, what you meant to come back to.

Notes are stripped from the exported mod, so nothing you write here can reach the player.

In the game, this looks like

Nothing. A note is a drawing aid and never runs.

Fields

Note

Shown on the canvas only. Notes are never exported into the mod.
Default
empty

Width

How wide the note is on the canvas, in pixels.
Default
240
Limits
160 to 640. Whole numbers, in steps of 20.

Wires

This node has no sockets of its own.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.
