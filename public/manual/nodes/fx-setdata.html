Set quest data

Effects  fx.setData

What it does

Stores a value under a name you choose, so a later node can read it back.

When you'd use it

Use it to remember something the player did: which door they opened, who they met, what they paid.

Read the value back with a Branch set to test quest data, or drop it into a message with a tag.

The name is yours to pick. Use the same name to read it back.

In the game, this looks like

Nothing appears on screen. The value sits in the quest's memory until something reads it.

Fields

Key

A name you choose, like doorCode. Use the same name later to read this value back.
Example
doorCode
Default
empty
If you leave it empty
The value is stored under no name, so nothing can find it again.

Value

Any text is fine — a word, a number, an address. It is just stored, so nothing here can error. You can also insert a live value by typing {{data.name}} for something you saved earlier.
Example
4417
Default
empty
Tags work here
Type {{data.something}} to insert a value you saved with Set quest data.
Watch out
The name has to match exactly when you read it back. A typo reads as an empty value and nothing warns you.

Wires

SocketDirectionWhat to connect
Ininput Whatever should run immediately before this node.
Outoutput Whatever should happen after this node runs.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Step by step: add this node to a quest

  1. Find Set quest data under Effects in the palette.
  2. Drag it onto the canvas at the moment the thing worth remembering happens.
  3. Type a name in Key and the thing to remember in Value.
  4. Later, add a Branch and set Test against to Data to read it.

Common mistakes

  • The name does not match when you read it back. Nothing warns you. The reader finds no value and treats it as empty.
  • A value is stored and never read. The node runs and changes nothing. Delete it, or use the value somewhere.

Messages you might see

  • Unreachable — nothing leads to this node, so the value is never stored

Related nodes

  • Charge the player — Takes money out of the player's account.
  • Notify — Puts a message on the player's screen.
  • Ask player — Asks the player a one-line question.
  • Claim another quest — Starts the next quest.
  • Complete quest — Finishes the current quest.
  • Retire quest — Removes the current quest without completion.
  • Unclaim quest — Removes a claimed quest.
  • Run terminal command — Runs a command in the player's terminal.
  • Open handbook — Opens an in-game article.
