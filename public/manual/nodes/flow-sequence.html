Sequence

Flow control  flow.sequence

What it does

Takes one input and fires as many outputs as you like, from the top down, with a pause before each.

When you'd use it

Use it for a beat that lands in pieces: a door opens, then the lights come up, then a message arrives.

Each row you add is a socket on the node, so the shape of the beat is visible on the canvas.

In the game, this looks like

The outputs happen one after another, spaced by the pauses you set.

Fields

Outputs, in order

They fire top to bottom. Drag the rows' ✕ to remove an output — any wire attached to it is removed too.
What to put here
One row per output, in the order they should fire.
Default
a starter list
Watch out
Removing a row removes its socket, and any wire attached to it goes with it.

The button reads Add output.

Name

Free text — whatever helps you recognise this output on the canvas, e.g. “lights out” or “call Mara”.
What to put here
A name for the output, so you can tell the sockets apart on the canvas.

Wait before firing (milliseconds)

How long to pause before this output fires, counted from the previous one. 0 fires it immediately; 1000 is one second.
Example
1500
Limits
0 or more. Whole numbers, in steps of 100.

Wires

SocketDirectionWhat to connect
Ininput Whatever should run immediately before this node.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Common mistakes

  • A row is deleted without checking its wire. The socket goes with it and whatever hung off it is orphaned.
  • Every pause left at zero. The whole beat lands in one instant and the player misses most of it.

Messages you might see

  • Unreachable — nothing leads to this node, so no output fires

Related nodes

  • Branch — Sends the story down one of two paths.
  • Wait — Pauses the story.
  • Timer — Fires the next node at a later in-game time — a delay, a clock time N in-game days from now, or a fixed in-game date.
  • Reroute — A tidy point for your wires.
  • Random pick — Picks one path at random.
  • Debug probe — Prints what is happening here.
