Create network

World building  world.network

What it does

Creates a network in the game's world: a router at the root, and every machine behind it, with their ports, users and weaknesses.

When you'd use it

Use it for any quest where the player has to break into something. The machines exist because your quest put them there.

Build the shape of the network in the Devices editor: the router first, then the machines the player has to reach behind it.

Leave the player a way in. A network with every port closed and no weakness to exploit is a wall, not a puzzle.

In the game, this looks like

The network appears in the game's world. The player can scan it, find what is open, and connect.

Fields

Devices

The router at the root of the network, plus everything behind it. Routers and splitters carry children; firewalls carry rules.
What to put here
The router at the root, and every machine behind it. The editor beside this field is where you add them.
Default
a starter set
Watch out
The player needs a route in. If the router exposes nothing and has no weakness, nothing behind it can be reached.

Also remove this network when the quest is completed

Off by default: the network stays in the world after the quest, the way a real company would. It is also safer, because deleting a machine the player is still connected to can hang the game. Abandoning the quest removes it either way.
What to put here
Turn this on to take the network back out of the world when the quest completes.
Default
off
Limits
On or off.

Wires

SocketDirectionWhat to connect
Ininput Whatever should run immediately before this node.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Step by step: add this node to a quest

  1. Find Create network under World building in the palette.
  2. Drag it onto the canvas early, before anything that depends on the machines existing.
  3. Open Devices and build the network: the router, then what sits behind it.
  4. Give the player a way in — an open port, or a weakness a scanner will report.
  5. Point later nodes at the machines with the address you stored in quest data.

Common mistakes

  • No route in. The player can see the network and cannot touch it. Open one port, or leave one weakness to find.
  • The network is created after the node that uses it. Wire it first. A node that targets a machine which does not exist yet finds nothing.

Messages you might see

  • Unreachable — nothing leads to this node, so the network is never created

Related nodes

  • Create Wi-Fi — Creates a wireless target the player can crack and join.
  • Firewall rule — Allows or blocks a port.
  • Change port — Opens, closes, adds or removes a port.
  • Register domain — Points a hostname at an address.
  • Create database — Data for the player to dig out.
  • Place files — Drops files on a machine.
  • Tool response — Scripts what a tool reports.
