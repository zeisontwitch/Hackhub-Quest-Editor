Story Beat

Layout  flow.beat

What it does

A planning card for one beat of your story. It is stripped from the exported mod and never runs.

When you'd use it

Use it to sketch a scene before you build it: what happens, and which ways it can go.

Each row under Branch choices becomes an output socket, so you can wire the paths out and see the shape of the scene.

In the game, this looks like

Nothing. The card is a planning aid, and the story passes through it unchanged.

Fields

Headline

A short name for this beat, e.g. “Act 2 — the firewall”. It is the card's title bar.
What to put here
The card's title bar. Name the beat after the scene.
Example
Act 2 — the firewall
Default
empty
If you leave it empty
The card has no title, so on a crowded canvas you cannot tell one beat from another.

Beat text

The key content of the beat. The card previews the top ~800 characters and expands into a scrollable panel for the rest.
What to put here
What happens in the beat. The card previews the top of it and expands in the inspector.
Default
empty

Branch choices

Add a row for each path the story can take. Each gets its own output socket on the card, so you can wire each branch onward while planning.
Default
an empty list

The button reads Add choice.

Choice

Short title for this path, e.g. “Go in through the front door”.
Example
Go in through the front door

What happens

One line on where this path leads, so a branching beat reads at a glance.

Width (px)

How wide the card is on the canvas, in pixels.
Default
280
Limits
200 to 640. Whole numbers, in steps of 20.

Card colour

Pick any colour. Colour-coding by act, character or branch is usually the clearest.
What to put here
Colour the card by act, character or branch, so a big canvas reads at a glance.
Default
"#64748b"

Wires

SocketDirectionWhat to connect
Ininput Whatever should run immediately before this node.
Outoutput Whatever should happen after this node runs.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Common mistakes

  • Expecting a beat to run. It is planning only and is stripped from the mod. Build the real beat with the nodes it describes.

Related nodes

  • Group frame — A named box that moves its nodes.
  • Sticky note — A comment on the canvas.
