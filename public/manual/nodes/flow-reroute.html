Reroute

Flow control  flow.reroute

What it does

A point to route wires through. It tidies the canvas and changes nothing about the story.

When you'd use it

Use it when one node has to feed several others, or when a wire would otherwise cross half the canvas.

Double-click any wire on the canvas to drop one in automatically.

In the game, this looks like

Nothing. It changes how the canvas looks, not how the quest runs.

Fields

This node has nothing to configure. It marks a moment in the story and runs whatever is wired after it.

Wires

SocketDirectionWhat to connect
Ininput Whatever should run immediately before this node.
Outoutput Whatever should happen after this node runs.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Common mistakes

  • Treating it as a choice. It has one input and one output and always passes the story through. For a decision, use Branch.

Related nodes

  • Branch — Sends the story down one of two paths.
  • Wait — Pauses the story.
  • Schedule beat — Runs part of the story at a later in-game time.
  • Random pick — Picks one path at random.
  • Sequence — Fires several outputs in order.
  • Debug probe — Prints what is happening here.
