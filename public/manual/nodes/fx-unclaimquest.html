Unclaim quest

Effects  fx.unclaimQuest

What it does

Unclaims a quest by name. Blank removes the quest this node belongs to.

When you'd use it

Use it to pull back a side job, reset a chapter handoff, or remove this quest without completion.

If you are ending a successful path, use Complete quest instead.

It has no output because the chosen quest is removed here.

In the game, this looks like

The named quest leaves the player's active list without counting as completed.

Fields

Quest

The identifier of the claimed quest to remove. Leave blank to remove this quest.
What to put here
Copy the internal name from the quest strip or the other mod notes. Blank targets this quest.
Example
side-contract
Default
empty
If you leave it empty
The current quest is removed.
Watch out
A spelling mismatch removes nothing, so the unwanted quest stays active.

Wires

SocketDirectionWhat to connect
Ininput The point where the chosen quest should be removed.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Step by step: add this node to a quest

  1. Find Unclaim quest under Effects.
  2. Type the quest identifier, or leave Quest blank for this quest.
  3. Wire the cancellation beat into its input.

Common mistakes

  • The wrong quest name is typed. Nothing is removed. Copy the identifier from the quest strip or the other mod's notes.
  • It replaces a success ending. The quest disappears without completion. Use Complete quest for success.

Messages you might see

  • Unreachable — nothing leads to this node, so no quest is unclaimed

Related nodes

  • Complete quest — Finishes the current quest.
