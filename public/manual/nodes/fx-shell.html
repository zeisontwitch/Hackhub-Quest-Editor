Run terminal command

Effects  fx.shell

What it does

Runs a command in the player's terminal as if they had typed it themselves.

When you'd use it

Use it when the story should do something in the terminal that the player has not done: start a scan, open a connection, leave output where they will find it.

Keep it to something a player could have typed. The output lands in their terminal, so it has to read like the real thing.

In the game, this looks like

The command appears in the player's terminal and its output follows, exactly as though they had run it.

Fields

Command

The command executed in the player's terminal, as if they had typed it. Tags like {{data.targetIp}} are filled in first.
What to put here
The command to run. Tags work here, so you can drop in a value you stored earlier.
Example
nmap {{data.targetIp}}
Default
empty
Tags work here
Type {{data.something}} to insert a value you saved with Set quest data.
If you leave it empty
There is nothing to run, so the node does nothing.
Watch out
It runs whether or not the player is ready for it. A command that needs an earlier step will fail in front of them.

Wires

SocketDirectionWhat to connect
Ininput Whatever should run immediately before this node.
Outoutput Whatever should happen after this node runs.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Step by step: add this node to a quest

  1. Find Run terminal command under Effects in the palette.
  2. Drag it onto the canvas at the point the command should run.
  3. Type the command, with tags for anything that changes per player.
  4. Add a Notify after it if the player should notice the output.

Common mistakes

  • The command depends on something the player has not done. It runs regardless and fails in their terminal. Move it after the step it needs.

Messages you might see

  • Unreachable — nothing leads to this node, so the command never runs
