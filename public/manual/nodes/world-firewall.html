Firewall rule

World building  world.firewall

What it does

Adds a firewall rule to a machine, so a port is open or closed to whoever you name.

When you'd use it

Use it to shut a door the player has to find another way through, or to open one at the right moment in the story.

Point it at the quest's own network, or at one machine you name.

In the game, this looks like

The player's scans show the port as blocked or reachable, depending on the rule.

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Common mistakes

  • The rule blocks the only way in. The player cannot finish. Either leave a route open, or make working around the block the puzzle.

Messages you might see

  • Unreachable — nothing leads to this node, so the rule is never applied

Related nodes

  • Create network — Builds the machines the player breaks into.
  • Create Wi-Fi — Creates a wireless target the player can crack and join.
  • Change port — Opens, closes, adds or removes a port.
  • Register domain — Points a hostname at an address.
  • Create database — Data for the player to dig out.
  • Place files — Drops files on a machine.
  • Tool response — Scripts what a tool reports.
