Create database

World building  world.database

What it does

Creates a database in the game's world, with a login and whatever tables you put in it.

When you'd use it

Use it when the player should dig something out of a system rather than read it in a file.

Give the player a way to find the password. A login nobody can discover is a dead end, not a puzzle.

In the game, this looks like

The player connects with a database client and queries the tables you built.

Fields

Host IP

The address the player points a database client at.
Example
{{data.targetIp}}
Default
empty
Tags work here
Type {{data.something}} to insert a value you saved with Set quest data.

Username

The login sqlmap or a client uses.
What to put here
The login the player uses.
Example
admin
Default
"admin"

Password

The password. Give the player a way to find it — a config file, a leaked dump, a cracked hash.
Default
"secret123"
Watch out
The default is a placeholder. Leave it in place and the player can guess their way in without playing.

Tables

The data inside: tables holding rows of named values, ready for the player's SQL.
Default
an empty list
If you leave it empty
The database exists and holds nothing, so there is nothing to find.

Remove when the quest ends

Drop the database when the quest ends.
Default
on
Limits
On or off.

Wires

SocketDirectionWhat to connect
Ininput Whatever should run immediately before this node.
Outoutput Whatever should happen after this node runs.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Common mistakes

  • No route to the password. The player finds the database and cannot open it. Hide the password somewhere they can reach.

Messages you might see

  • Unreachable — nothing leads to this node, so the database is never created

Related nodes

  • Create network — Builds the machines the player breaks into.
  • Create Wi-Fi — Creates a wireless target the player can crack and join.
  • Firewall rule — Allows or blocks a port.
  • Change port — Opens, closes, adds or removes a port.
  • Register domain — Points a hostname at an address.
  • Place files — Drops files on a machine.
  • Tool response — Scripts what a tool reports.
