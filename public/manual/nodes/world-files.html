Place files

World building  world.files

What it does

Creates files and folders on a machine — the player's own, or one you name.

When you'd use it

Use it for the clues the player has to find: a config with a password in it, a log with the right timestamp, a note somebody should not have written down.

Pick whose filesystem you are writing to. The player's own machine is written when the story reaches this node.

In the game, this looks like

The files appear in the filesystem, and the player finds them with the usual commands.

Fields

Where

Whose filesystem to write to. The player's own machine is written when the flow reaches this node; a remote device is mounted with the machine, under the account the player lands in, so the files are already there when they break in.
Default
"player"

One of the 2 listed below.
Watch out
Both fields below stay visible whichever you pick, and <b class="ui">Device IP</b> is only read for a remote device.

Only used for a remote device. Use the same {{data.targetIp}} token you gave the network, and the files are mounted on that machine before the player ever connects.

Parent folder

Where the files are mounted. Folders named etc, home, logs or lib are merged into the existing ones rather than replacing them.
Example
~/docs

"~/"
Watch out
Folders named etc, home, logs or lib are merged into the machine's real ones rather than created fresh.

The files and folders to create. A folder named etc, home, logs or lib merges with the machine's existing one.

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Step by step: add this node to a quest

  1. Find Place files under World building in the palette.
  2. Pick whose machine you are writing to.
  3. Set the parent folder, then add one row per file.
  4. Put the clue in Contents, written the way the file would really read.
  5. Mark anything the player should stumble on by accident as hidden.

Common mistakes

  • The clue is written like a note from the author. A config file that says "the password is hunter2, good luck" breaks the fiction. Write it the way the real file would look.
  • Files placed on the player's machine by mistake. Check Where. Writing to the player's own filesystem is very visible to them.

Messages you might see

  • Unreachable — nothing leads to this node, so no files are written
