Addon node

Community addons  pack.node

What it does

Runs a node supplied by a community addon instead of one built into the editor.

When you'd use it

Use it when an addon adds something the editor does not have. Addon nodes appear under Editor Mods in the palette.

You need the addon installed. Without it the node has nothing to run, and the player misses whatever it was meant to do.

In the game, this looks like

Whatever the addon's node does, at the point the story reaches it.

Fields

This node has no fields of its own. Pick an installed addon and one of its nodes, and the editor shows whatever that node asks for. With no addon installed there is nothing here to configure.

Wires

SocketDirectionWhat to connect
Ininput Whatever should run immediately before this node.
Outoutput Whatever should happen after this node runs.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Common mistakes

  • The story depends on an addon the player does not have. The node does nothing and the quest stalls. Check what your quest needs before you ship it.

Messages you might see

  • Unreachable — nothing leads to this node, so the addon node never runs

Related nodes

  • Give data to an addon — Fills in a data shape from an addon.
