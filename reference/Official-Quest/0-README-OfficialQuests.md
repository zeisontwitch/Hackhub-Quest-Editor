All of the .md files in this directory are write-downs of the official quests the game ships with. 

"The Journalist's Sister" is a long, connected line of quests that flow into each other, that tell the biggest story of the game. 

Every document describes what the player has to do, which commands the player uses, and what the output of those commands is.

In general, the game mostly uses automatically generated IP addresses, names, email addresses, accounts, IBAN addresses and so on. If it can generate them, it tends to do so except in a few quests like the Journalist's Sister line, where at the very least all names are hardcoded.
