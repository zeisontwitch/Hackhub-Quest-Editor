Give data to an addon

Community addons  world.packData

What it does

Hands a filled-in data shape to a community addon.

When you'd use it

Use it when an addon your quest depends on asks for data. Pick the pack, pick the shape, fill in what it wants.

You need the addon installed to see its fields. Nothing appears here until it is.

In the game, this looks like

The addon receives the values you entered when the story reaches this node.

Fields

This node has no fields of its own. Pick an installed addon pack and one of its data shapes, and the editor shows that pack's own fields for you to fill in. With no addon installed there is nothing here to configure.

Wires

SocketDirectionWhat to connect
Ininput Whatever should run immediately before this node.
Outoutput Whatever should happen after this node runs.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Common mistakes

  • The addon is not installed. The player has your quest and not the addon it hands data to. Ship them together, or say so up front.

Messages you might see

  • Unreachable — nothing leads to this node, so the addon never receives the data
