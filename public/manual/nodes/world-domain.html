Register domain

World building  world.domain

What it does

Registers a hostname in the game's world and points it at the address you choose.

When you'd use it

Use it to give the player a name to find instead of a bare address. A company they look up should resolve to something.

Add the weaknesses on the host behind the name, and the game's scanners report them when the player looks.

In the game, this looks like

The player looks the name up and gets the address you gave it.

Fields

Domain

The hostname the player types, e.g. vault.corp-internal.net.
Example
vault.corp-internal.net
Default
empty
If you leave it empty
There is no name to resolve, so the node does nothing.

Resolves to

The address it resolves to. nslookup and dig will report this.
Default
empty
Tags work here
Type {{data.something}} to insert a value you saved with Set quest data.

Vulnerabilities

Weaknesses on the host behind this name. In-game scanners report them when the player probes it.
What to put here
The weaknesses on the host behind this name. A scanner reports the ones you list.
Default
an empty list

The button reads Add vulnerability.

Type

The kind of weakness this machine has. The in-game scanners report it when the player probes the machine.
What to put here
The kind of weakness. Each one says what the player can do with it.
Limits
One of the 7 listed below.

The affected component's version, e.g. "WordPress 5.8". Cosmetic unless a trigger matches on it.

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Common mistakes

  • The name resolves to an address that does not exist. The player finds the hostname and reaches nothing. Point it at a machine your quest actually creates.

Messages you might see

  • Unreachable — nothing leads to this node, so the name is never registered

Related nodes

  • Create network — Builds the machines the player breaks into.
  • Create Wi-Fi — Creates a wireless target the player can crack and join.
  • Firewall rule — Allows or blocks a port.
  • Change port — Opens, closes, adds or removes a port.
  • Create database — Data for the player to dig out.
  • Place files — Drops files on a machine.
  • Tool response — Scripts what a tool reports.
