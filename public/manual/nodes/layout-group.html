Group frame

Layout  layout.group

What it does

A named box around part of your canvas. Drag it and everything inside moves with it.

When you'd use it

Use it to keep a long quest readable: one frame per act, per location, or per character.

It changes nothing about how the quest runs. Its name and comment still travel with the export.

In the game, this looks like

The frame itself never runs. Its Name and Comment do ship: the export writes each group as a comment near the top of the mod, so somebody reading that file without this editor can still follow how you laid the quest out. Sticky notes ship nothing at all.

Fields

Name

Shown in the frame's title bar — name the cluster after what it does, e.g. “Act 1: recon”.
Default
"Group"

Title bar colour

Colour-code your frames however you like — e.g. one colour per act, or per character. It only changes how the frame looks in the editor.
Default
"#64748b"

Comment

A note to future-you about what this cluster does.
What to put here
Worth writing as though a stranger will read it, because they might. This text is the part of the frame that survives into the exported mod.
Default
empty
Watch out
A comment containing the two characters that close a block comment cannot break the export. The compiler escapes it for you.

Wires

This node has no sockets of its own.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.
