Twotter

Communication  comms.tweet

What it does

A post on Twotter, the game's social network. The node posts from one of your mod's accounts, so a character can have a public voice your players can look up and read.

When you'd use it

Use it when the story is something the player should be able to find rather than be told: a missing person's last posts, a company account issuing a flat denial, a journalist building a case in public.

Several rows on one node make a history. Set them to Already on the profile with ages of weeks or months and the account has been living in the world since long before the quest began.

One row set to When the story arrives posts as the flow reaches the node — the player is watching it land, seconds old. That is the shape for a post the story itself provokes.

In the game, this looks like

The profile in the in-game Twotter app shows the account's name, handle, picture and the posts. Players can search for a handle there, and a post with Also in the main timeline switched on also turns up in the public feed everyone sees.

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Step by step: add this node to a quest

  1. Find Twotter under Communication in the palette.
  2. Drag it onto the canvas where the posts belong, and wire it into the story.
  3. Pick the account that posts. If the character does not exist yet, use Manage accounts — accounts belong to the whole mod, so the same one can post in several quests.
  4. Write the first tweet. Set When to Already on the profile and give it an age if it should have been there all along.
  5. Press Add a tweet for each further post. Write them oldest first — that is the order they happened.
  6. Fill in the numbers the post shows: likes, replies, reposts and views. They are decoration, and they are what makes an account look real.

Common mistakes

  • Numbers that do not add up. A post with four thousand views and one like reads as invented. Keep the figures in proportion to how many followers the account has.
  • A handle the game will not accept. Handles take letters, numbers and underscores, three to fifteen characters. The compiler says so before you export, and an account nothing can find is a clue the player never gets.
  • Ages that run the wrong way. A row marked Already on the profile counts back from the moment the story reaches the node, so ages further down the list should be smaller, not larger.

Messages you might see

  • No account to post as — the node has no account chosen, so nothing is posted
  • Nothing to post — the node has no tweet rows, so it does nothing at all
