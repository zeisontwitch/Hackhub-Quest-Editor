On quest complete

Quest lifecycle  entry.complete

What it does

Runs when the quest is marked complete. That can come from a Complete quest node, auto-complete, or the player's Complete button.

When you'd use it

Use it for cleanup or epilogue beats that should happen after the quest is finished.

For a deliberate ending, place Complete quest where the story should finish.

Anything wired here runs after that finish point, not before it.

In the game, this looks like

The player sees the quest finish, then this path runs through the game's quest-complete hook.

Fields

This node has nothing to configure. It marks a moment in the story and runs whatever is wired after it.

Wires

SocketDirectionWhat to connect
Outoutput Whatever should happen after this node runs.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Step by step: add this node to a quest

  1. Find On quest complete under Quest lifecycle.
  2. Wire its Out socket to the epilogue work.
  3. Make sure your graph has a Complete quest node, or enable another finish path in Behaviour.

Common mistakes

  • No finish path exists. The node waits forever. Add Complete quest to the final beat, or enable another finish path.
  • Important story happens only here. If completion is skipped, the player misses it. Put critical mail or clues before Complete quest.

Messages you might see

  • Only runs on completion — the editor warns you when this graph has no Complete quest node

Related nodes

  • Quest start — Runs once, when the quest is claimed.
  • On start & reload — Runs on claim, and again on every load.
  • On quest abandoned — Runs if the player gives up.
