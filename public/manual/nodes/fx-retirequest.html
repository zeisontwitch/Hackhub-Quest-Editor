Retire quest

Effects  fx.retireQuest

What it does

Takes this quest out of the player's active list without marking it complete.

When you'd use it

Use it for fail states, cancelled jobs, or stories that should vanish without rewards.

Do not use it for a normal success ending. Use Complete quest for that.

It has no output because the current story path ends here.

In the game, this looks like

The quest disappears from the active list. It does not count as completed.

Fields

This node has nothing to configure. It marks a moment in the story and runs whatever is wired after it.

Wires

SocketDirectionWhat to connect
Ininput The point where the quest should be removed.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Step by step: add this node to a quest

  1. Find Retire quest under Effects.
  2. Place it at the end of the path that cancels the job.
  3. Wire the fail or cancellation beat into its input.

Common mistakes

  • It is used for success. The player may miss rewards and complete-only follow-up. Use Complete quest instead.
  • It runs before the player reads the reason. The quest vanishes with no explanation. Send the closing message first.

Messages you might see

  • Unreachable — nothing leads to this node, so the quest is never retired

Related nodes

  • Charge the player — Takes money out of the player's account.
