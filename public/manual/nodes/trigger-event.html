When event

Triggers  trigger.event

What it does

Watches for a single game event and fires when it happens. This is how your quest hears the player.

When you'd use it

Wire one into an objective's Trigger socket to make that objective tick over when the player does the thing.

Wire one into a Branch to make the story react. The event carries details with it, and the branch can test them.

It has no input socket. A trigger is not part of the flow — it sits alongside it and fires on its own.

In the game, this looks like

Nothing appears on screen. The event fires inside the game and your quest reacts a moment later.

Fields

Game event

All supported HackHub events, listed with the details each one carries.
Default
empty
If you leave it empty
There is nothing to listen for, so the node never fires.

Only when

Leave empty to fire on any occurrence.
What to put here
Add one clause per thing that has to be true.
Default
an empty list
Watch out
The same action can raise more than one event. Check the list for the one that carries the details you need.

Wires

SocketDirectionWhat to connect
Whenoutput The objective or branch that should react when the event fires.

Then runs next When tests a condition Unlocks opens an objective Data carries a value

A wire only joins two sockets of the same colour, and the editor draws the wire in that colour. That is what the colours are for: match the colours and the connection takes, mismatch them and it will not.

Step by step: add this node to a quest

  1. Find When event under Triggers in the palette.
  2. Drag it onto the canvas, next to the objective it should tick over.
  3. Pick the game event that means the player did the thing.
  4. Drag a wire from its When socket into the objective's Trigger socket.
  5. Add a clause under Only when if the event should not count every time it happens.

Common mistakes

  • The wire went into the objective's In socket. The two sockets are different colours for exactly this reason. In is flow, Trigger is a condition.
  • No clauses, so the trigger is too loose. The objective ticks over on the first occurrence, which may be before the player got there.
  • The event picked is not the one the action raises. The player does the thing and nothing happens. Check the event list for what your action really fires.
