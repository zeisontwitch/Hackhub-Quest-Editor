## Tester quick start

This is a QA harness, not a normal quest. The in-game objectives are reminders for checks; they are not meant to form a story path, and you can skip a row if it is confusing or risky.

Start with the raw mod and run this in the in-game terminal:

```text
qe24 guide
```

The short smoke pass is:

1. `qe24 http-fetch` — expected: prints status `200` and JSON/body text; the `http-response` objective should tick if `Http.Response` fires.
2. `qe24 schedule 1` — expected: after the game clock advances or you use the Wait button, a scheduler mail/toast appears and `scheduler-fired` ticks.
3. `qe24 collab` — expected: it prints a `curl http://...` command; running that command ticks `collaborator-hit`.
4. Connect to Wi-Fi `QE24-RAW-5G` with passphrase `correct-horse-battery`, then disconnect — expected: the Wi-Fi objectives tick and the scan shows BSSID/channel/WPS.
5. Completion API probes are separate: run `qe24 claim complete`, then `qe24 complete`; later test `button`, `retire`, and `unclaim` the same way.

### What is "intercept"?

Intercept is the new SDK 0.24 proxy-style HTTP hold switch. When it is on, the game can pause a browser/`curl` request, emit `Http.Intercepted`, and wait for a tool to forward or drop that request. It is useful for future proxy/Burp-like nodes, but it is a footgun if left on.

Use two terminal windows because the terminal running `curl` may wait until another terminal forwards the request:

```text
# Terminal A
qe24 intercept on
curl http://qe24-http.test/

# Terminal B
qe24 intercept queue
qe24 intercept forward
qe24 intercept off
```

Expected: `http-intercepted` ticks, `qe24 intercept queue` shows one held `GET`, and the waiting `curl` prints the page after `forward`. If anything seems stuck, run `qe24 intercept off` in another terminal. If two terminals are inconvenient, skip this row and mark it `Blocked`.

### What changed in SDK 0.24 that this checks?

- HTTP/curl event surface: `Http.Request`, `Http.Response`, `Http.Intercepted`, and `Http.CollaboratorHit`.
- Native Wi-Fi creation: BSSID/channel/WPS plus connection/disconnection payloads.
- Time/Scheduler APIs: jobs scheduled on game time and Wait/save-load behavior.
- Quest lifecycle APIs/fixes: `this.complete()`, `this.retire()`, `Quest.unclaim()`, final-objective freeze and abandoned-quest cleanup.
